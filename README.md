# PORTFOLIO-WEBPAGE
A portfolio website created to showcase my skills, projects, education, and journey as a developer.

The website provides a simple and professional overview of who I am, the technologies I work with, and the projects I have built. It also includes links to my professional profiles and a contact section for getting in touch.

## 🚀 Getting Started

To run this project locally, follow these steps.

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_LINK
```

### 2. Open the project folder

```bash
cd portfolio-new
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

After running the command, open the local URL shown in the terminal.

## 📦 Build for Production

To create a production build, run:

```bash
npm run build
```

This will create a `dist` folder containing the files required for deployment.
